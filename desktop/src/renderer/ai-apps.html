Connect your AI apps

Pick an AI app to connect OpenDoc to it, so that a session in that app can find OpenDoc and make documents with it. Nothing is changed until you press Connect, and every result is shown here. You can disconnect at any time.

      How to use it
      
    
      Point your agent at this skill, or copy the folder to the place where your agent reads skills. The agent must be able to run the opendoc command.
      
    
      Chat apps that cannot run programs on this computer, such as ChatGPT or the chat in the Claude app, cannot use OpenDoc.
